# Prompt Help — სწორი პრომპტის ფორმატი

მომხმარებლის ბოლო დავალება/პრომპტი შეაფასე და:

## 1. ხარისხის შეფასება (1-5)

| ქულა | მნიშვნელობა |
|-------|------------|
| 1 | ძალიან ბუნდოვანი — არაფერია დაზუსტებული |
| 2 | ზოგადი — აკლია ფაილები ან სერვისი |
| 3 | საშუალო — მოთხოვნა ნათელია, მაგრამ აკლია კონტექსტი |
| 4 | კარგი — ფაილები + მოთხოვნა + სერვისი მითითებულია |
| 5 | შესანიშნავი — ლინკები, edge cases, verification criteria ყველაფერი არის |

## 2. რა აკლია?

შეამოწმე ეს კრიტერიუმები:

**სავალდებულო:**
- [ ] კონკრეტული ფაილები მითითებულია?
- [ ] მკაფიო მოთხოვნა — ზუსტად რა უნდა გაკეთდეს?
- [ ] სერვისი იდენტიფიცირებულია (Plugin_Frontend, Website_Backend...)?

**სასურველი:**
- [ ] Reference ლინკები (API docs, design specs)?
- [ ] Edge cases აღწერილია?
- [ ] Verification criteria — როგორ გადავამოწმოთ?

## 3. გაუმჯობესებული ვერსია

აჩვენე როგორ გამოიყურებოდა იგივე დავალება სწორი ფორმატით. გამოიყენე CLAUDE.md-ის Prompt Templates სექციიდან შესაბამისი შაბლონი:

- **Bug Fix** — პრობლემა + reproduce steps + expected/actual
- **New Feature** — feature + service + files + behavior + edge cases
- **Test Writing** — file + scenarios + framework
- **Refactoring** — what + file + goal + constraints
