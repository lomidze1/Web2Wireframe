# მომხმარებლის ინტერვიუ — სკრიპტი და სინთეზი

## რატომ არის ეს გადაუდებელი

2+ თვე ჩაიდო რენდერის fidelity-ში (ფონტები, SVG, flex-wrap, blend modes,
Visual Match). ეს მუშაობა **არავის მოთხოვნაზე არ ყოფილა დაფუძნებული** —
0 კომენტარი, 0 review, 0 საუბარი მომხმარებელთან. ტესტ-საიტებიც შიგნიდან
შეირჩა (telex.ge, iwm.org.uk, wikipedia).

შესაძლოა fidelity ზუსტად ისაა, რაც საჭიროა. შესაძლოა არა. **ამის ცოდნა
ამჟამად შეუძლებელია** — და ეს ყველაზე ძვირი ფარული ხარჯია ბიზნესში.

## ვის ველაპარაკოთ (პრიორიტეტით)

1. **ვინც უკვე დააინსტალა** (65 ადამიანი) — ყველაზე ღირებული. თუ მათი
   მიღწევა შესაძლებელია, დაიწყე აქედან.
2. **ციფრული სააგენტოები** — redesign/audit მათი ყოველდღიური სამუშაოა;
   volume-ს აღწევენ, ე.ი. paid-ის რეალური სეგმენტია.
3. **ფრილანსერი product დიზაინერები** — h2d-ის ბირთვული აუდიტორია.
4. **h2d-ის უკმაყოფილო მომხმარებლები** — მოძებნე h2d-ის Community
   კომენტარებში და Reddit-ზე ჩივილები. ეს მზა სია დიფერენციაციისთვის.
