## 3. Technical Insight (ტექსტი)

არა-სარეკლამო პოსტი, რომელიც აჩვენებს რომ იცი რას აკეთებ. ეს არის ის,
რაც დიზაინერს/დეველოპერს აყოლებს.

**თემები, რომლებიც ჩვენს კოდში უკვე ამოხსნილია:**
- რატომ ტყდება ვებ-გვერდის ფონტები Figma-ში (SFNT სახელი ≠ CSS სახელი)
- `line-height: normal` — რატომ არ არის 1.2 და რატომ ცდება ყველა კონვერტორი
- margin collapse — CSS-ის წესი, რომელსაც Auto Layout-ს ვერ ატან
- რატომ ხდება icon font-ი Inter-ად კონვერტაციისას

**წესი:** პოსტის 80% = სასარგებლო ცოდნა. 20% = „ჩვენ ეს გავაკეთეთ".
არასოდეს პირიქით.
