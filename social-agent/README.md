# Social Agent — სამუშაო ადგილი

აქ **იგეგმება და სრულდება** ყველაფერი, რაც სოც-არხებზე მიდის.
გეგმაც აქ წერია, ნედლი მასალაც აქ დევს, მზა შედეგიც აქედან იტვირთება.

კითხულობს და წერს: `social-agent` აგენტი, `/social` და `/youtube-short` სკილები.

```
social-agent/
├── QUEUE.md                        ← რა არის გადასაღები, თანმიმდევრობით
├── 01) video/
│   ├── development/                ← ყველაფერი მუშა
│   │   ├── CONTENT-PLAN.md         ← YouTube-ის კონტენტ-სტრატეგია
│   │   ├── FEEDBACK.md             ← 🔴 გემოვნების ჟურნალი — ყოველი სესიის წინ წაიკითხე
│   │   ├── scripts/NN-<slug>/      ← სცენარები + VO ტექსტი + `vo/*.m4a`
│   │   ├── shorts/NN-<slug>/       ← build-სკრიპტი + შუალედური რენდერები
│   │   └── raw/                    ← ნედლი ჩანაწერები
│   │       ├── videos/  images/  used/
│   └── production/                 ← მხოლოდ ასატვირთი
└── 02) articles/
    ├── development/
    │   └── CONTENT-LOG.md          ← 🔴 რა დაიპოსტა უკვე — არ გაიმეორო
    └── production/                 ← მხოლოდ დასაპოსტად დამტკიცებული
```

## 🔴 development ↔ production — ხისტი წესი

| | |
|---|---|
| `development/` | ვერსიები, დრაფტები, ნედლი ჩანაწერები, build-სკრიპტები, ხმები |
| `production/` | **მხოლოდ ის, რაც გიორგიმ დაამტკიცა** |

**`production/`-ში ყოველ ფაილს თან უნდა ახლდეს იმავე სახელის `.md`**
სათაურითა და აღწერით:

```
01) video/production/apple-import.mp4
01) video/production/apple-import.md      ← title + description
```

ამის გარეშე ატვირთვა შეუძლებელია.

🚫 **არასდროს ჩადო რამე `production/`-ში დადასტურების გარეშე.**
ვერსიები (`-v2`, `-v3`) რჩება `development/`-ში; არსებულ ფაილს ადგილზე ნუ გადააწერ.

## როგორ ვიმუშაო ამით

1. გადაიღე მასალა → ჩააგდე `01) video/development/raw/videos/` ან `/images/`-ში
2. ახალ ჩატში: **„social-agent — ახალი მასალა ავტვირთე"**
3. ან უბრალოდ: **„რა მაქვს გადასაღები?"** → აგენტი `QUEUE.md`-ს გიკითხავს
   და ერთ კონკრეტულ დავალებას მოგცემს

**ფაილის სახელი:** `YYYY-MM-DD_თემა.mp4` — მაგ. `2026-08-26_linear-import.mp4`.
თარიღი და თემა საკმარისია, დანარჩენს აგენტი გაარკვევს.

დაპოსტვის შემდეგ ნედლი ფაილი გადადის `raw/used/`-ში, ხოლო ჩანაწერი ემატება
`02) articles/development/CONTENT-LOG.md`-ს.
