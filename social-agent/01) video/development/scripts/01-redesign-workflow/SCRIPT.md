| # | VO (ინგლისური) | კადრი |
|---|----------------|-------|
| 01 | Redesigning a website that already exists is a different job from designing a new one. | ცოცხალი საიტი ბრაუზერში, ნელი სქროლი |
| 02 | You are not starting from a blank canvas. You are starting from something that already works, that people already use. | იგივე, ჩერდება hero-ზე |
| 03 | And the slowest part is usually the same: getting what already exists into Figma so you can actually work with it. | ცარიელი Figma კანვასი, კურსორი ელოდება |
| 04 | Most people do this by hand. Screenshot the page, drop it in, and rebuild the sections on top of it. | სქრინშოტი კანვასზე, მართკუთხედები იხატება ხელით |
| 05 | It works. It also takes an afternoon, and at the end you have a picture, not a layout. | იგივე, უძრავი სურათი — ლეიერები არ არის |
| 06 | Here is the workflow I use instead. Three steps. | სათაურის ბარათი: `Three steps` |
| 07 | Step one. Bring the current site in as real layers. | სექციის ბარათი: `1 — Bring it in` |
| 08 | I use a plugin called Web2Wireframe. Paste the URL, and it parses the live page into Figma frames. | პლაგინის პანელი, URL იწერება |
| 09 | Text stays text. Auto layout stays auto layout. The site's own fonts come through. | შედეგი კანვასზე, ლეიერების პანელი გახსნილი |
| 10 | It will not be a perfect copy. Nothing is. But it is a real layout you can select, edit and measure — not a flat image. | ლეიერზე დაწკაპუნება, ტექსტის რედაქტირება ადგილზე |
| 11 | Step two. Decide what you are keeping before you import. | სექციის ბარათი: `2 — Decide what you keep` |
| 12 | This is the part most people skip, and it is the part that saves the afternoon. | პარამეტრების პანელი, ნელა |
| 13 | If you are keeping the content and changing the look, bring in the real text and swap the palette for your own. | ვარიანტი A: რეალური ტექსტი + საკუთარი პალიტრა |
| 14 | If you are changing the structure, bring in placeholders at the original character counts instead. Same rhythm, none of the noise. | ვარიანტი B: placeholder + Lorem, გვერდიგვერდ |
| 15 | And if your design system runs on variables, generate those instead of raw hex values. | ვარიანტი C: Figma ცვლადების პანელი |
| 16 | Same page, same import, a different starting file each time. | სამივე ვარიანტი გვერდიგვერდ ⭐ |
| 17 | Step three. Work from the baseline, not from a screenshot. | სექციის ბარათი: `3 — Work from it` |
| 18 | Now you have the old design and the new one in the same file, at the same scale. | ორი frame გვერდიგვერდ |

| 20 | And when someone asks why a section moved, you have the before, not a memory of it. | გამოკვეთილი სექცია before/after |

## რას ვიღებ ეკრანზე (გიორგისთვის)

ერთი უწყვეტი ჩანაწერი, ამ თანმიმდევრობით. **ხმა არ სჭირდება.**

1. `plausible.io` ბრაუზერში — ნელი სქროლი ზემოდან ქვემოთ (~15წმ)
2. ცარიელი Figma კანვასი, კურსორი (~5წმ)
3. სქრინშოტის ჩაგდება კანვასზე + 2–3 მართკუთხედის ხელით დახატვა (~15წმ)
4. პლაგინის გახსნა → URL-ის ჩაწერა → **პარამეტრების პანელი ნელა** → Import (~20წმ)
5. შედეგი კანვასზე + **ლეიერების პანელის გახსნა** + ერთ ტექსტზე დაწკაპუნება და რედაქტირება (~20წმ)
6. კიდევ **ორი იმპორტი** სხვა პარამეტრებით: placeholder+Lorem, და ცვლადები (~40წმ)
7. სამივე შედეგი გვერდიგვერდ, zoom out (~10წმ)

**სულ ~2 წუთი ჩანაწერი.** მე გავწელავ და გავჭრი ხმაზე.
⚠️ spinner-ს გადავახტები — შენ უბრალოდ ნუ გააჩერებ ჩაწერას.
