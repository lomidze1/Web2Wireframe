# Short A — „Stop rebuilding websites by hand"

**ხანგრძლივობა:** ~24წმ · **მიზანი:** ტოპ-ფანელი, პრობლემის ცნობა

| # | VO | კადრი | წმ |
|---|-----|-------|-----|
| A1 | This is how most people get a website into Figma. | სქრინშოტი კანვასზე | 0.0–3.0 |
| A2 | Screenshot the page. Drop it in. Then draw every box on top of it by hand. | მართკუთხედები იხატება ხელით, ერთმანეთის მიყოლებით | 3.0–8.5 |
| A3 | An afternoon later you have a picture. Not a layout. | გაყინული კადრი — ბრტყელი სურათი, ლეიერები არ არის | 8.5–12.5 |
| A4 | Or you paste the URL and get real frames. Text you can retype. Auto layout that holds. | პლაგინი: URL → Import → შედეგი ლეიერებით | 12.5–19.0 |
| A5 | Same page. Two very different afternoons. | ორივე გვერდიგვერდ | 19.0–22.0 |
| A6 | — | end card: `Web2Wireframe` · `Figma Community` | 22.0–24.0 |

**Hook-ის კადრი (0.0წმ):** ეკრანზე უკვე ჩანს ხელით დახატული მართკუთხედები —
