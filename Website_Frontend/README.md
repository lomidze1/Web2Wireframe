# Website_Frontend

Marketing site and support form UI built with React + Vite.

## Setup

```bash
npm install
```

Create `.env.local` from the example:

```bash
cp .env.local.example .env.local
```

Set the backend URL:

```env
VITE_API_URL=http://localhost:3001
```

## Development

```bash
npm run dev
```

Vite defaults to `http://localhost:5173` (it may choose another port if busy).

## Build

```bash
npm run build
```

Build output is in `dist`.
