# Web2Wireframe

Web2Wireframe is a monorepo with the website and Figma plugin projects.

## Repository Structure

```
Web 2 Wireframe/
├── Website_Frontend/     # Marketing site + support form UI
├── Website_Backend/      # Support API (Express + TypeScript)
├── Plugin_Frontend/      # Figma plugin UI
└── Plugin_Backend/       # Backend service for the plugin
```
